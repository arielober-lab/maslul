# מסלול — אפליקציית חלוקה

אפליקציית PWA לנהגי חלוקה: מדביקים רשימה מוואטסאפ, מקבלים מסלול עם ניווט,
חיוג והודעות מוכנות. הכל רץ בדפדפן, בלי שרת ובלי בסיס נתונים.

## הקבצים

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה — ממשק, לוגיקה ועיצוב |
| `parser.js` | המפענח: מקבל טקסט חופשי בעברית ומחזיר עצירות |
| `manifest.json` | מה שהופך את זה לאפליקציה שנוספת למסך הבית |
| `sw.js` | Service worker — שומר את האפליקציה לשימוש אופליין |
| `icon-*.png` | אייקונים |
| `test.js` | בדיקות למפענח מול רשימות אמיתיות (`node test.js`) |
| `e2e.js` | בדיקת דפדפן מלאה (`node e2e.js`) |

## אירוח

קבצים סטטיים בלבד — כל שרת אינטרנט יגיש אותם כמו שהם.

שני תנאים כדי שההתקנה למסך הבית תעבוד:

1. **HTTPS.** ללא זה הדפדפן לא ירשום service worker ולא יציע התקנה.
   (`localhost` פטור, לפיתוח.)
2. **כל הקבצים באותה תיקייה**, כי `manifest.json` ו-`sw.js` מופנים יחסית.

## מה עובד ומה לא

- **ניווט** — Waze מקבל את הכתובת כטקסט, בלי צורך ב-API בתשלום.
- **חיוג** — קישור `tel:`, עם כפתור העתקה כגיבוי.
- **וואטסאפ** — קישורי `wa.me` עם טקסט מוכן. פותח את השיחה, לא שולח לבד.
- **סידור אוטומטי** — דרך Nominatim של OpenStreetMap. חינמי, מוגבל לבקשה
  לשנייה, ולא תמיד מוצא כתובות ישראליות. נכשל בעדינות — הסידור הידני נשאר.

## פרטיות

הרשימות מכילות שמות, כתובות וטלפונים של מקבלי סיוע. זה מידע רגיש.

- **אחסון** — הכל ב-`localStorage` של המכשיר, לא מוצפן. שום שרת לא מעורב
  ואין חשבונות.
- **שמירה ומחיקה** — רשימה נמחקת בשלוש דרכים: כפתור בסוף המסלול, כפתור
  בהגדרות, ואוטומטית בפתיחה אם עברו יותר משלושה ימים מאז המגע האחרון בה
  (`MAX_AGE_MS`). ההגדרות האישיות של הנהג נשמרות בכל המקרים.
  המחיקה האוטומטית פועלת **בפתיחת האפליקציה**, לא ברקע: PWA לא רץ כשהוא
  סגור, ולכן אסור להבטיח למשתמש מחיקה בשעה מסוימת.
- **מה כן יוצא מהמכשיר** — רק כשהמשתמש לוחץ:
  - *סידור אוטומטי* שולח את **הכתובות** ל-Nominatim (בלי שמות וטלפונים).
  - *ניווט* שולח את הכתובת ל-Waze או ל-Google Maps.
  - *וואטסאפ* פותח שיחה עם המספר דרך `wa.me`.
- **קבצי הבדיקה** — `test.js` ו-`e2e.js` משתמשים ברשימות **מומצאות** בלבד.
  הריפו ציבורי: אל תכניס אליהם רשימה אמיתית, גם לא זמנית.

## עדכון גרסה

אחרי כל שינוי בקבצים, שנה את `CACHE` ב-`sw.js` (למשל `maslul-v2`).
בלי זה משתמשים שכבר התקינו ימשיכו לראות את הגרסה הישנה.
